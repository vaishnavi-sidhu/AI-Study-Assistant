# AI-Study-Assistant
## Overview
AI Study Assistant helps students create personalized study plans, summarize notes, generate quizzes, and manage exam revisions.
## Features
- Study Plan Generator
- Notes Summarizer
- Quiz Generator
- Revision Planner
## Problem Statment
Students often struggle to organize study schedules and revise efficiently before exams.
## Solution
AI Study Assistant uses AI-powered guidance to help students plan, learn, and revise effectively.

- Python
- GitHub
- Aritificial Intelligence
